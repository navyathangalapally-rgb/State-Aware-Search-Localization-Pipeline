# State-Aware-Search-and-Localization-Pipeline
Automated Multilingual Help Documentation SystemThis repository contains the core technical components of an automated documentation pipeline developed for the BioSphere Infiniti bio-sensing platform. The system transitions legacy, static documentation into an interactive, high-performance web-based help environment integrated via Microsoft WebView2.  🚀 Project OverviewIn clinical environments, therapists require instant, searchable access to troubleshooting steps and sensor calibration guides. This project solved the bottleneck of static manuals by engineering a "zero-dependency" search engine and a Python-based localization pipeline.  Key Technical AchievementsPerformance Optimization: Refactored documentation by stripping Base64 encoded strings and standardizing assets, reducing the memory footprint by over 80%.  State-Aware Search: Developed a JavaScript search engine that preserves DOM integrity by caching the originalState before applying RegEx-based highlighting.  Automated Localization: Built a BeautifulSoup4 pipeline to automate text extraction and image path flattening for English, German, and Polish versions.  🛠️ Tech StackFrontend: HTML5, CSS3 (Modern UI/Sticky Headers), JavaScript (ES6+).  Backend/Automation: Python 3.x, BeautifulSoup4.  Tools: Pandoc (Document Conversion), Microsoft WebView2.  📂 Repository Structure🎨 abi.css (Frontend Architecture)Standardizes the visual presentation of medical software screenshots.  Implements standard-screenshot class for responsive scaling.  Features a sticky search header to ensure navigation tools are always accessible during long calibration menus.  🔍 search.js (Interactive Logic)Handles the interactive search engine within the WebView2 environment.  Regex-Based Processing: Isolates keywords without breaking HTML tags.  Smooth Navigation: Automatically scrolls the viewport to the first identified search match.  🤖 localize.py (Automation Pipeline)A Python utility designed to maintain version parity across multiple languages.  Path Repairing: Automatically flattens complex relative paths to ensure portability across clinical workstations.  Targeted Parsing: Extracts only specific text nodes (<p>, <td>, <h1>) to protect functional HTML attributes during translation.  📈 ImpactThe implementation ensured that clinical documentation remains pixel-perfect and responsive, allowing medical professionals to interpret biological data without software lag or navigation difficulties.
